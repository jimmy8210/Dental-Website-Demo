# Apex Dental & Implant Centre 🦷

A modern, high-converting, mobile-first website for a premier Indian dental clinic specializing in Painless Dentistry, Advanced Dental Implants, Clear Aligners, and Cosmetic Smile Makeovers.

Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

---

## 🌟 Key Features

- **Centralized Configuration (`src/config/clinicData.ts`)**: Easily swap clinic name, chief doctor credentials, city/locality, phone numbers, Google reviews, OPD hours, and Web3Forms keys in a single file.
- **Top Info Strip & Sticky Navbar**: Displays split OPD timings (`10:00 AM – 2:00 PM | 5:00 PM – 9:00 PM`), location badge, and clickable phone call links.
- **Hero Section**: Google Trust Pill (`⭐ 4.9/5 Rating on Google • 2,500+ Happy Smiles Restored`), primary WhatsApp CTA, and 4 trust metrics.
- **High-Margin Treatments Grid (6 Cards)**: Dental Implants, Clear Aligners, Painless Single-Sitting RCT, Smile Makeover, Zirconia Crowns, and Pediatric Dentistry—each with an **"Ask Cost on WhatsApp"** button.
- **Hospital-Grade 4-Step Sterilization**: Dark navy/teal banner explaining ultrasonic cleaning, individual sterile pouches, Class-B autoclave, and 100% single-use consumables.
- **Chief Dental Surgeon Profile**: Credentials and philosophy for Dr. Ananya Mukherjee, BDS, MDS.
- **Interactive Before & After Smile Slider**: Touch- and mouse-draggable comparison slider for real clinical transformations.
- **Verified Google Reviews**: Cards featuring authentic Indian patient testimonials and Google 5-star ratings.
- **Dental Anxiety & FAQs**: Accordion answering patient concerns on painlessness, 0% EMI financing, and infection control.
- **Split OPD Hours & Instant Appointment Form**: Connected to Web3Forms with Indian mobile number validation (`^[6-9]\d{9}$`) and a 1-tap **"Confirm Instantly on WhatsApp"** sync button.
- **Mobile-First Conversion Boosters**: Fixed bottom 50/50 split sticky bar (`📞 Call Clinic` & `💬 WhatsApp`) on mobile and floating WhatsApp widget on desktop.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS (Custom teal, mint-ice, and navy medical palette)
- **Icons:** Lucide React
- **Forms:** Web3Forms API + Direct WhatsApp click-to-chat integration

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/jimmy8210/Dental-Website-Demo.git
cd Dental-Website-Demo
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
